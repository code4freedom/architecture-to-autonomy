Domain composition

10 practice tests

Each test is a fixed 60-item form built to the blueprint weights (16/11/12/12/9), timed at 120 minutes. Options are reshuffled on every attempt. Your best score per test is stored in this browser.

Custom length

Any length, built to the same weights. Timed runs allow 2 minutes per item. Each run continues from where the last one stopped in the bank, so consecutive runs draw different items.
